## Project Overview
This project takes live weather data from the National Weather Service API and presents a 7 day forecast. Using the matplotlib library, this project also plots a graph with the temperatures to show how the temperature fluctuates over the next 7 days.
## Dependencies/Libraries
The following Python libraries were used:

- requests
- pandas
- numpy
- matplotlib
- pytest

## How to Run
1. Open Jupyter Notebook

2. Open `main.ipynb`

3. Run first cell to install dependencies
```bash
pip install -r requirements.txt
```
4. Run second cell to run the program
